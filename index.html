Approach 2: Use Constructor Injection with @RequiredArgsConstructor and @Transactional(readOnly = true)

Field injection via @Autowired is an anti-pattern in modern Spring Boot apps because it breaks immutability, hides dependencies, and complicates unit testing with Mockito. Switching to constructor injection ensures all dependencies are fully initialized before any service method is executed.

Additionally, marking read-only service queries with @Transactional(readOnly = true) keeps the Hibernate persistence session open throughout DTO mapping and enables Hibernate to optimize flush modes:

@Service
@RequiredArgsConstructor
@Transactional(readOnly = true)
public class OrderServiceImpl implements OrderService {

    private final OrderRepository orderRepository;
    private final UserMapper userMapper;

    @Override
    public OrderDTO getOrderDetails(Long orderId) {
        Order order = orderRepository.findByIdWithItems(orderId)
            .orElseThrow(() -> new EntityNotFoundException("Order not found with id: " + orderId));

        return userMapper.toDto(order);
    }
}

Notice that final fields guarantee non-null bean references, preventing arbitrary NullPointerException at runtime if a dependency fails to autowire.

Approach 3: Prevent N+1 issues using Spring Data JPA @EntityGraph or Java 21 Record DTO Projections

If your LazyInitializationException occurs when mapping collection relations (like Order.items or Order.customer), using @EntityGraph instructs Spring Data JPA to perform an immediate SQL LEFT OUTER JOIN, preventing detached proxy errors.

In modern Spring Boot 3, using Java 21 Records for constructor query projection is even faster because it completely bypasses the Hibernate first-level cache:

public interface OrderRepository extends JpaRepository<Order, Long> {

    // Solution A: Fetch graph for eager loading specific relations in one single query
    @EntityGraph(attributePaths = {"orderItems", "customer"})
    Optional<Order> findWithItemsById(Long id);

    // Solution B: Java 21 Record Projection (skips Hibernate persistence context)
    @Query("""
        SELECT new com.example.dto.OrderSummaryDTO(o.id, o.status, c.email, COUNT(i.id))
        FROM Order o
        JOIN o.customer c
        LEFT JOIN o.orderItems i
        WHERE o.id = :id
        GROUP BY o.id, o.status, c.email
    """)
    Optional<OrderSummaryDTO> findSummaryById(@Param("id") Long id);
}
