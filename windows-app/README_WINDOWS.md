# Windows App — اپلیکیشن پس‌زمینه‌ی مستقل ویندوز

این اپلیکیشن به‌صورت مستقل در پس‌زمینه‌ی ویندوز (**System Tray**) اجرا می‌شود و در **همه‌ی برنامه‌های ویندوز** (Chrome، Google Docs، Edge، Firefox، Word، PDF، VS Code و ...) بدون نیاز به نصب هیچ اکستنشن مرورگر یا Python کار می‌کند.

## اجرا
فقط کافیست فایل `WindowsApp.exe` را اجرا کنید (در گوشه پایین-راست نوار وظیفه کنار ساعت با آیکون آبی `W` فعال می‌شود).

## میانبرهای سراسری ویندوز (حتی با کیبورد فارسی)
- **`Ctrl + Shift + X`** یا **`Ctrl + Shift + A`** یا **`Ctrl + Shift + راست‌کلیک`**:
  - اگر متنی انتخاب شده باشد (در Google Docs، مرورگر، Word، PDF و هر برنامه‌ی دیگر): متن انتخاب‌شده را خودکار می‌خواند، پردازش می‌کند، پاسخ را در کلیپ‌بورد کپی می‌کند و تیک آبی `✓` نشان می‌دهد؛ بلافاصله `Ctrl + V` بزنید.
  - اگر هیچ متنی انتخاب نشده باشد: ابزار **کراپ اسکرین‌شات صفحه** باز می‌شود؛ محدوده را با ماوس بکشید تا تحلیل و پاسخ در کلیپ‌بورد کپی شود.
- **`Alt + Shift + S`**: پردازش مستقیم متن یا تصویر موجود در کلیپ‌بورد (مثلاً اسکرین‌شات `Win+Shift+S`).
- **`Ctrl + Alt + Shift + S`**: باز کردن مستقیم ابزار کراپ اسکرین‌شات.
- **`Alt + Shift + C`**: باز کردن پنجره تنظیمات و تاریخچه.

## بیلد مجدد از سورس
اگر `WindowsApp.cs` را ویرایش کردید، فایل `build_windows_app.bat` را اجرا کنید تا `WindowsApp.exe` دوباره ساخته شود.
